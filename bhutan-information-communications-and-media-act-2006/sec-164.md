# JURISDICTION IN REM CIVIL ACTIONS AGAINST DOMAIN NAME
# VIOLATORS
164. The owner of a trade mark may file an in rem civil action against a domain name in the jurisdiction in which the domain name registrar, domain name registry, or other domain name authority that registered or assigned the domain name is located if the:
(a) domain name violates any right of the owner of a registered or protected trade mark, or
(b) Court finds that the owner is not able to obtain in personam jurisdiction over a person who would have been a defendant in a civil action under this Section.
